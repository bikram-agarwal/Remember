# Remember

**Notes, lists, reminders - done right**

Android app for tasks and notes, with on-device storage and optional backup and imports.

- **Project site (GitHub Pages):** [bikram-agarwal.github.io/Remember](https://bikram-agarwal.github.io/Remember/)
- **Privacy policy:** [bikram-agarwal.github.io/Remember/privacy.html](https://bikram-agarwal.github.io/Remember/privacy.html)
- **Play Store:** [Remember on Google Play](https://play.google.com/store/apps/details?id=dev.bikram.remember)

## Build

This repository is a standard Gradle Android project. Open it in Android Studio or run `./gradlew assembleDebug` from the project root.
